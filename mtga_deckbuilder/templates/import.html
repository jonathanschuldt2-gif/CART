Where do I get an export?

Arena has no export button for your collection, so use a collection tracker that reads it:

  • Untapped.gg companion: Collection → Export (CSV).
  • Aetherhub / MTGA Assistant tracker: Collection → Export.
  • Moxfield / Deckstats collections: Export CSV.
  • Any CSV works if it has a name column (Name/Card), and ideally Quantity/Count, Set, Collector Number or an Arena ID column.
  • Arena deck text (4 Card Name (SET) 123) also works, e.g. to add a few cards.
