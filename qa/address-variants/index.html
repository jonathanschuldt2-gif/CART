Address Route Checker

Paste shipping address variants, route each one back to its original address using USPS Publication 28 rules, then confirm the result against Google — either automatically with a Google Maps API key or manually on google.com.

1. Original addresses

The clean addresses variants should route back to. Add more rows to test routing between similar addresses.

2. Variants

Paste rows from Excel (tab-separated) or CSV: Line 1, Line 2, City, Zip. A leading row number and a header row are detected automatically.

3. Google verification

Without a key, every result row has Google Maps and Google Search links to check it on google.com and Pass / Fail buttons to record your verdict. With a Google Maps Platform key, the tool checks each variant automatically: a variant passes when Google resolves it to the same place as the original.

Key setup

In Google Cloud Console enable the Maps JavaScript API (for Geocoding mode, which also needs the Geocoding API) and/or the Address Validation API. Restrict the key to HTTP referrers where you host this page. The key is only sent to Google; it is stored locally only if you tick "Remember key".
